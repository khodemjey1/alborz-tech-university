# پورتال رسمی دانشگاه فنی البرز

یک وب‌سایت دانشگاهی مدرن، پیشرفته، و کاملاً ریسپانسیو (بهینه‌سازی‌شده برای تمامی نمایشگرهای موبایل، تبلت و دسکتاپ) که به صورت دوصفحه‌ای با زبان‌های استاندارد توسعه وب (HTML, CSS, JavaScript) پیاده‌سازی شده است.

## ویژگی‌های فنی پروژه:
- **طراحی کاملاً ریسپانسیو (Responsive):** استفاده از چیدمان‌های مدرن CSS Grid و Flexbox همراه با Media Queries جامع، جهت تضمین پایداری و زیبایی در هر رزولوشنی.
- **پشتیبانی کامل از تم تاریک/روشن (Light/Dark Mode):** قابلیت سوئیچ بین حالت تیره و روشن با استفاده از CSS Variables همراه با همگام‌سازی و ذخیره‌سازی ترجیحات کاربر در حافظه محلی مرورگر (`LocalStorage`).
- **فیلترینگ و جستجوی پویا در صفحه دوره‌ها:** مجهز به موتور کارآمد و پویا در زبانِ جاوااسکریپت برای فیلتر کردن طبقه‌بندی دپارتمان‌ها و جستجوی زمان‌واقعی (Real-Time Search) بدون نیاز به بارگذاری مجدد صفحه.
- **کنترل و همگام‌سازی با پارامترهای آدرس (Query Params Matching):** امکان پیمایش مستقیم به فیلتر دلخواه با ارسال پارامتر در URL (به عنوان مثال `courses.html?filter=it`).
- **افکت‌های Glassmorphism و انیمیشن‌های ملایم:** منوی مه‌آلود شناور زیبا، ترنزیشن‌های انیمیشنی فرم‌ها و افکت‌های هاور مدرن.
- **توسعه بومی راست‌چین (RTL - Right to Left):** استفاده از فونت استاندارد و زیبای وزیر متن (Vazirmatn) جهت ارائه‌ی بهترین خوانایی فارسی.

## فایل‌های پروژه:
۱. `index.html`: خانه و پورتال اصلی معرفی دانشگاه، دپارتمان‌ها و فرم مشاوره.
۲. `courses.html`: دپارتمان‌های آموزشی فعال مجهز به منوی فیلتر و جستجوی لحظه‌ای.
۳. `style.css`: شیت یکپارچه استایل‌دهی، متغیرها، گرید رید دات‌پی و تم تاریک.
۴. `main.js`: مدیریت منو موبایل، تغییرات تم‌ها و اعمال منطق فیلتر و فرم‌ها.
